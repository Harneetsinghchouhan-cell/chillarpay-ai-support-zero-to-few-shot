# ChillarPay: AI Customer Support — Zero-Shot to Few-Shot

## 1. Project Introduction

ChillarPay is a fictional UPI payment application created for this FinTech case study. The project explores how Artificial Intelligence can help manage customer-support messages by identifying customer problems, assigning priority levels and preparing suitable replies.

## 2. Business Problem

ChillarPay receives approximately 2,000 customer-support messages every day. Its six-member support team faces challenges in handling messages quickly and correctly.

The main problems include:
- Failed payments
- Pending refunds
- Fraud alerts
- Account and KYC issues

The objective is to test whether AI can make customer-support work faster and more organised.

## 3. Project Objectives

- Classify customer messages into the correct category.
- Assign High, Medium or Low priority.
- Generate short and polite customer replies.
- Understand the difference between zero-shot and few-shot prompting.
- Evaluate AI performance using a prepared answer key.

## 4. Dataset

The project uses 12 fictional customer-support messages.

The messages cover four categories:

1. Failed Payment
2. Refund
3. Fraud Alert
4. Account & KYC

A separate answer key was prepared before testing to evaluate the AI results.

## 5. Experiments Performed

| Step | Experiment | Purpose |
|---|---|---|
| Step 1 | Case Study Introduction | Understand the business problem |
| Step 2 | Dataset Creation | Prepare fictional customer messages |
| Step 3 | Answer Key | Define correct categories and priorities |
| Step 4 | Zero-Shot Summarisation | Test AI summarisation using instructions |
| Step 5 | Zero-Shot Triage | Test classification, priority and reply generation |
| Step 6 | Few-Shot Triage | Test whether three examples improve results |
| Step 7 | Score Comparison | Compare both prompting methods |

## 6. Evaluation

The two prompting methods are evaluated using:

- Correct category
- Correct priority
- Reply tone
- Required table format

The results are documented in the evaluation scorecard.

## 7. Key Learning

This project demonstrates that:
- Simple instructions can be enough for basic summarisation.
- Examples can help AI understand business-specific rules.
- AI may still make mistakes when business rules are unclear.
- Human review is important before using AI-generated customer replies.

## 9. Conclusion

The case study compares zero-shot and few-shot prompting for customer-support automation. It highlights how examples can improve AI responses while also showing the importance of clear business rules and human supervision.
